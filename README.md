# Cartwright Legal

Cartwright（カートライト）アプリの法的情報を公開するリポジトリです。

## 公開URL

GitHub Pagesにより以下のURLで公開されます。

- ホーム: `https://[your-username].github.io/cartwright-legal/`
- プライバシーポリシー: `https://[your-username].github.io/cartwright-legal/privacy.html`
- 利用規約: `https://[your-username].github.io/cartwright-legal/terms.html`

## 構成

- `index.html`: トップページ
- `privacy.html`: プライバシーポリシー（HTML版）
- `privacy.md`: プライバシーポリシー（Markdown版）
- `terms.html`: 利用規約（HTML版）
- `terms.md`: 利用規約（Markdown版）

## 更新方法

`privacy.md` または `terms.md` を編集後、対応する `.html` ファイルも更新してください。
